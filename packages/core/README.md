# @chilekit/core

Utilidades sin dependencias ni red de [ChileKit](https://github.com/ferando855/chilekit):

- Fechas: `todayInChile`, `toChileDate`, `isIsoDate`.
- RUT: `validateRut`, `formatRut`, `calculateRutCheckDigit`. Validación local de dígito
  verificador; no consulta identidades.
- Texto no confiable: `sanitizeText`, `sanitizeUrl`.
- Tipos compartidos: `Holiday`, `EconomicIndicator`, `ChileCommune`, `SourceManifest`.
